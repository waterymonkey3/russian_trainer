# 俄语学习系统（本地自用）

双击 **`start.bat`** 即可使用：会启动一个本地服务并自动打开浏览器（默认 http://127.0.0.1:8765/ ）。
关闭那个黑色命令行窗口就等于退出程序。

## 数据来源（只读引用，不改动原文件）

| 用途 | 来源 |
|---|---|
| 词条（俄文、重音拼写、词性、中文、英文、例句、词频） | `../russian_flashcards/vocabulary.csv`（3200 词） |
| 发音音频 | `../russian_flashcards/audio/*.mp3`（3200 条 TTS 发音，与词条一一对应） |
| 学习进度 | `data/progress.json`（本目录，自动生成） |

## 五个模块

**词汇书** —— 3200 词完整列表，每页 20 条，可翻页、跳页、搜索；显示带重音符号的俄文、词性、中文、英文、例句，可点 🔊 听发音，并标注「已掌握 / 复习中 / 错题 N」状态。

**抄写** —— 每页 10 词，显示中英文翻译与俄文原文；**点输入框自动播放读音**，输入后失焦会**再播一次并自动比对**，不相符时旁边提示并给出正确写法。抄写只练手感，**不影响任何进度**。

**默写** —— 每页 10 词，只给中英文翻译（不显示俄文原文，可手动点「例句」）；点输入框播读音，失焦后判分：

- 写对：累计正确次数 +1，**连对 3 次进入「已掌握」**；
- 写错：错误次数 +1、正确次数清零，并出现「显示答案」按钮；以后进入「已掌握」所需连对次数变成 **3 + 错误次数**；
- 本页 10 词全部提交过，底部「下一页」才会亮起。

**复习节奏**：每学一组 10 词后就进入下一组新词，同时旧组会在 **2、4、8、16… 页之后**再次出现（间隔逐次翻倍），直到该组所有词都掌握为止。

**已掌握** —— 默写达标后进入，按「距上次正确默写的天数」从久到近排列（可切成词频顺序），支持搜索、分页；每行可点「复习」把词送回抄写/默写（**保持已掌握状态，写对一次即通过、天数重新计时；写错则移出已掌握、错误 +1、正确次数清零**）。
本模块还包含：自动纳入复习开关 + 天数阈值（默认超过 **30 天**未正确默写就自动加入复习队列）。

**错题本** —— 自动记录默写写错的词与次数，默认按错误次数从多到少排列，可切「最近出错 / 词频顺序」，支持搜索分页；词进入「已掌握」后自动移出。

**其他** —— 抄写与默写各有「学习 / 复习(N)」两个标签页；页码会被记住，下次打开回到上次的位置；内置可关闭的**俄文字母虚拟键盘**：按真实俄文键盘（ЙЦУКЕН）排成三排——

```
ё й ц у к е н г ш щ з х ъ
  ф ы в а п р о л д ж э
    я ч с м и т ь б ю -
       [空格] [⌫ 删除]
```

（真实的俄文键盘上连字符在数字排、句点在第三排末尾；这里把连字符放在第三排末位，因为 `что-то` 这类词必须打连字符。点字母即可插入到上一个点过的输入框光标处，没装俄语输入法也能默写。）

**键盘开关常驻右下角**：展开时是深色的「⌨ 收起键盘」，收起后变成蓝色的「⌨ 展开键盘」停在右下角，随时点一下就回来；它和「已掌握」页里的键盘复选框是同一个开关，两边状态自动同步（写在 `settings.virtualKeyboard` 里，重启也记得）。

## 输入判定规则（宽松）

忽略大小写、首尾与多余空格、重音符号、常见标点与引号，**ё 与 е 等价**；连字符需要输入（`что-то` 不能写成 `чтото`）。

## 回车键快捷操作（抄写 / 默写）

- **输入框里按回车** = 失焦判分：再播一次读音，然后比对/判分（抄写提示相符或不相符，默写判对错、记进度）。
- **没有聚焦任何输入框时按回车** = 光标自动跳到本页**从上到下第一个「空着或写错」的输入框**（按同一套宽松规则判断对错），并把它滚到屏幕中间；已经写对的格子会被跳过。
- **本页全部写对时再按回车** = 直接翻到下一页（默写页走的是和「下一页」按钮完全相同的排期逻辑，包括 2、4、8… 页的重逢安排），翻页后光标自动落在新页第一格；已经是最后一页时只提示「…已经是最后一页了」。
- 于是可以一路「打一个词 → 回车判分 → 回车跳下一格 → 整页写完回车翻页」把整本书敲完。
- 焦点在按钮、下拉等控件上时，回车仍然只作用于那个控件（不会把光标抢走）。

## 参数想改的话

| 想改什么 | 改哪里 |
|---|---|
| 每页词数（10）、列表每页条数（20） | `web/logic.js` 顶部的 `PER_PAGE` / `LIST_PAGE` |
| 进入已掌握所需基础正确次数（3） | `web/logic.js` 的 `MASTER_BASE` |
| 复习间隔底数（2 → 2、4、8、16…） | `web/logic.js` 的 `RECITE_GAP_BASE` |
| 默认端口、自动打开浏览器 | `server.py --port 9000 --no-browser`，或改 `start.bat` |

## 进度与备份

- 进度实时写入 `data/progress.json`（原子写入，不会写坏）。
- 每天第一次保存时会留一份快照到 `data/backup/`，只保留最近 7 份。
- 如果进度文件损坏，启动时会自动改名留档并回退到最近的备份。
- 想从头开始学，删除 `data/progress.json` 即可（建议先备份）。

```bash
node tools/assets.test.mjs    # 前端 id、class、模块引用一致性
node tools/ui.test.mjs        # 用 DOM 桩把抄写/默写/复习流程跑一遍
```

## 依赖

运行只需要 **Python 3**（标准库，无需 pip 安装任何东西）；界面不依赖任何外部资源（无 CDN、无联网）。
Node 只是在跑自检脚本时才需要。
